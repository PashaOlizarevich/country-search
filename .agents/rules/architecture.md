# Архитектура и контракты

Применяется к исходникам, интерфейсам модулей и настройке проекта. Основание: [архитектура](../../docs/ARCHITECTURE.md), [стек](../../docs/STACK.md), [ТЗ](../../docs/TASK.md).

## Технологии и границы

- Сохраняй TypeScript, DOM API, обычный CSS, npm и компиляцию `tsc` в ES-модули. UI-фреймворк, сборщик и сервер не вводи без согласования; собственный backend или прокси не входит в ТЗ.
- Распределяй код по ответственности существующих `api`, `models`, `search`, `utils`, `ui`, `styles`; `main.ts` соединяет модули. Полное распределение смотри в документе архитектуры.
- Запросы, преобразование данных, debounce и контроллер поиска не зависят от DOM. UI отображает состояние и передаёт действия; не переносит к себе правила запросов и ошибок.
- Сохраняй строгие проверки TypeScript. Для внешних данных используй проверку и сужение типов; не подменяй их `any`, необоснованным приведением или отключением проверки.
- В относительных TypeScript-импортах указывай выходное расширение `.js`. Не используй алиасы или импорты пакетов в браузерном коде, которые не разрешаются текущей схемой публикации.
- `body` содержит только скрипт; разметка создаётся DOM API. Данные выводятся как текст, без динамических `innerHTML` и `insertAdjacentHTML`.

## Поисковый контракт

- Проверяй фактическую схему countries.dev перед закреплением типов. Используй `fetch`, передавая сигнал отмены; проверяй `response.ok`. Отсутствующие сведения не выдумывай.
- 404 означает пустой результат. Прочие HTTP-ошибки представляются `HttpError` со статусом; сетевые ошибки и таймаут отображаются как ошибки.
- Различай `AbortError`, `TimeoutError` и `HttpError`. Собственная отмена не отображается как ошибка. Объедини отмену по вводу и таймаут, сохранив различие причин.
- При каждом изменении ввода сразу отменяй активный запрос, до ожидания debounce. При очистке отменяется и отложенный запуск, список очищается, новый поиск не отправляется.
- Повтор использует последний текущий запрос. Запоздавшие ответы не возвращают старые результаты; одного игнорирования ответа вместо настоящей отмены недостаточно.
- Debounce и бонусное кэширование реализуются самостоятельно, без готовых библиотек. Бонусы не добавляются в обязательный объём автоматически.
- При публикации учитывай HTML, CSS и ассеты: `tsc` не является упаковщиком статических ресурсов.
