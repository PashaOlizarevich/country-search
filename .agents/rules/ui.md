# Интерфейс и визуальные эффекты

Применяется к UI, CSS, поведению в браузере, доступности и сцене флага. Подробные значения, композиция и критерии хранятся в [дизайн-проекте](../../docs/DESIGN_PROJECT.md).

- Сохраняй выбранную светлую студийную композицию, стеклянные поверхности, объёмные карточки и центральный тканевый флаг. Не заменяй визуальное направление без запроса.
- Обеспечь состояния пустого ввода, загрузки, результатов, отсутствия совпадений, настоящей ошибки и повтора. Декоративный пример не показывай как найденную через API страну.
- Для визуального этапа допустимы явно демонстрационные данные. Перед подключением рабочего поиска убери подставные результаты; пустое поле не должно запускать поиск.
- Сохраняй клавиатурное управление, подписи поля и кнопок, видимый фокус, управление фокусом диалога, адаптивность и читаемость на стеклянных поверхностях. Данные страны должны быть доступны вне canvas.
- Сохраняй пропорции и рисунок флагов. Отсутствие изображения или эффектов не должно ломать карточку и поиск.
- Реалистичная тканевая анимация — отдельная задача будущего WebGL-модуля, а не уже установленная технология или готовый ассет. Не выдавай CSS-покачивание плоской картинки за завершённую сцену ткани.
- Для сцены учитывай CORS текстур, смену страны, устаревшие загрузки и освобождение ресурсов. Не вводи сервер или прокси ради эффекта.
- Предусматривай остановку движения, reduced motion, приостановку вне видимости и статичный вариант при недоступном WebGL. Сбой декорации не превращается в ошибку поиска.
- После изменения отображения проверь затронутые состояния в браузере: узкую и широкую ширину, длинные данные, клавиатуру, Console; для запросов — Network и отмену. Для анимации отдельно проверь reduced motion и статичный режим.
- Пользуйся доступной браузерной диагностикой. Если рендер проверить невозможно, укажи ограничение; анализ CSS и чтение кода не называй визуальной проверкой.
