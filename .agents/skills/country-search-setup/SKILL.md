# Настройка инструментов Country Search

## Контекст

Прочитай [AGENTS.md](../../../AGENTS.md), [прогресс](../../../docs/progress.md), [стек](../../../docs/STACK.md) и относящиеся к задаче конфигурации. Применяй [общие правила](../../rules/workflow.md), [архитектуру](../../rules/architecture.md) и [TDD и проверки](../../rules/testing.md).

## Выполнение

1. Установи фактическое состояние: версии Node.js и npm, зависимости в manifest и lock-файле, наличие локальных исполняемых файлов, существующие scripts и хуки. Отдели отсутствие пакета от ошибки конфигурации.
2. Для нужных версий проверь официальную документацию и совместимость. Сохрани компиляцию приложения через `tsc` без добавления сборщика; зависимости тестового инструмента не считай основанием менять сборку приложения.
3. Подготовь минимальный набор изменений. Если требуется установка, используй уже данное разрешение либо представь конкретные пакеты, версии и назначение для согласования до установки. Глобальные пакеты не нужны.
4. Выполни разрешённую настройку. Сохрани возможность красного тестового коммита: lint-staged в pre-commit, тесты в pre-push. Не запускай hooks setup как способ неявно создать Git-репозиторий.
5. Проверь изменённые команды и конфигурации. Для хуков по возможности используй безопасный запуск без настоящего commit или push; непроверенную блокировку отправки обозначь отдельно.

## Результат

Обнови прогресс и изменившиеся сведения о настройке в документации. Сообщи, какие команды работают, какие зависимости действительно установлены и что остаётся неподготовленным для TDD. Настройка считается завершённой по результатам команд, а не по наличию файлов.
