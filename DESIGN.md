# Country Search — проектные решения

Пункт 9 завершён: базовые модули проверены отдельно. UI пока использует демоданные; контроллер и интеграция ещё не реализованы.

## 1. Отмена запросов

src/api/searchCountries.ts передаёт полученный AbortSignal непосредственно fetch. Ошибки запроса и чтения тела не перехватываются и сохраняют причину. src/api/errors.ts различает AbortError и TimeoutError по name; HttpError хранит HTTP-статус. Текстовый 404 превращается в пустой результат до response.json(). Тест с реагирующим на signal мок-запросом подтверждает реальную отмену.

Отмена сразу при вводе, композиция с таймаутом и защита состояния от запоздавших ответов относятся к контроллеру пункта 10. Их пока нельзя считать реализованными; отдельный тест гонки относится к пункту 11.

## 2. Задержка debounce

src/utils/debounce.ts использует один таймер на обёртку: новый вызов отменяет предыдущий и сохраняет последние аргументы в callback таймера. cancel() отменяет ожидающий вызов. Перед вызовом callback ссылка на таймер сбрасывается, поэтому повторное планирование из callback работает.

Фактическая задержка поиска будет выбрана при реализации контроллера; 300 мс в тестах — параметр сценария. Без задержки каждый ввод запускал бы запрос, слишком большая задержка ухудшила бы отклик. Debounce самостоятельно не отменяет уже начатый fetch.

## 3. Сложность

mapCountryResponse обрабатывает одну страну. Время O(S), где S — суммарный размер просматриваемых строк и элементов языков, валют и границ; дополнительная память O(S) для нормализованных строк и новых массивов. searchCountries последовательно преобразует все записи, поэтому сложность линейна по суммарному размеру этих данных. Бонусный кэш отсутствует.

## 4. Разделение ответственности

mapCountryResponse принимает unknown, проверяет данные и возвращает новую модель Country без мутации источника. HTTP-статусы обрабатывает searchCountries, классификацию причин — classifySearchError; UI эти модули не импортируют. Debounce не знает о сети или странах. Тесты используют локальные fixtures, mock fetch и управляемые таймеры.
