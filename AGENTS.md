# Инструкции для работы с Country Search

Действуют для `country-search` и вложенных папок. Ты — senior software engineer и архитектурный помощник проекта. Отвечай на русском, работай самостоятельно в пределах запроса и сохраняй существующие решения.

## Начало работы

1. Прочитай [общие правила](.agents/rules/workflow.md); они применяются ко всем задачам.
2. Перед feature, refactor или bugfix прочитай [прогресс](docs/progress.md) и сверь его с кодом и конфигурацией. Документированная возможность не считается реализованной без кода.
3. По таблице ниже загрузи только относящиеся к задаче правила и `SKILL.md`, затем связанные файлы. При сочетании задач используй несколько подходящих строк.

Правила задают постоянные ограничения, навыки — способ выполнения конкретной работы. Не загружай все навыки для каждой задачи. Они дополняют текущий запрос и не дают разрешений на установку пакетов или Git-действия.

## Как подключаются инструкции

Проектные навыки находятся в `.agents/skills/<имя>/SKILL.md`. Если навык обнаружен клиентом, его можно вызвать как `$country-search-setup`, `$country-search-logic` или `$country-search-ui`. Если его ещё нет в списке, открой указанный `SKILL.md` напрямую и следуй ему для подходящей задачи.

Файлы `.agents/rules/*.md` — Markdown-инструкции проекта: прочитай их по таблице, они не подключаются автоматически как отдельный тип конфигурации. Файлы политики запуска команд `.codex/rules/*.rules` этой задачей не создаются и не изменяются.

Для автоматического обнаружения запускай Codex с рабочей папкой `country-search`. При работе из родительской `rsschool` сначала явно прочитай этот файл и нужный навык по пути. Изменения файлов не означают, что клиент уже перечитал их.
