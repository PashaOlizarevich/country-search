# Макеты Country Search

Пункт 2 [плана](../IMPLEMENTATION_PLAN.md). Это статичные дизайнерские материалы. Интерфейс приложения реализован на демоданных в пункте 4; API и анимация ещё не подключены. Композицию и исходник макетов подготовил субагент; основной агент выполнил генерацию изображений, уточнение по дизайн-проекту и экспорт.

## Просмотр

Открыть [mockups.html](mockups.html). Состояние выбирается параметром `?state=initial`, `results`, `loading`, `empty`, `error` или `details`. При работающем локальном сервере: `http://127.0.0.1:8080/docs/design/mockups.html?state=initial`.

Точный ориентир реализации — эти 12 PNG и значения [дизайн-проекта](../DESIGN_PROJECT.md). Варианты [concept-desktop.png](concept-desktop.png) и [concept-mobile.png](concept-mobile.png) фиксируют художественное направление ImageGen, а не точные размеры и типографику. Экспорты уточняют концепты по исходным требованиям: поиск шириной до 640 px, поле с текстом 16 px, компактная сцена при результатах, доступные размеры кнопок, системный шрифт и текстовый источник данных.

## Происхождение и условия использования

- `concept-desktop.png`, `concept-mobile.png`, `flag-cloth-reference.png` созданы встроенным OpenAI ImageGen 2026-11-12 по описанию этого проекта; сторонние фотографии и готовые макеты не использовались. Действуют условия используемого сервиса OpenAI: [Terms of Use, Content](https://openai.com/policies/terms-of-use/). Это AI-generated output, а не материал с лицензией Creative Commons; отдельная сторонняя лицензия инструментом не предоставлена.
- `flag-cloth-reference.png` — прозрачный статичный референс ткани, света и складок. Генеративные отклонения геометрии не переносятся в текстуру флага: для неё подготовлен точный [jp.svg](../../assets/flags/jp.svg). Происхождение и статус символики — в [assets/README.md](../../assets/README.md).
- `mockups.html` создан для проекта; PNG `desktop-*` и `mobile-*` — его браузерные экспорты с указанным тканевым референсом. Новая лицензия на код проекта этим документом не вводится.
- Данные Japan в макетах демонстрационные и не подтверждают текущий ответ API. В первом экране, загрузке, ошибке и пустом результате флаг подписан как визуальный пример. При результатах он обозначает Japan.
- Системные шрифты не копируются в репозиторий. Значки — локальная простая SVG-геометрия. Внешние пакеты и шрифты не добавлены.

## Проверка экспортов

Все 12 PNG проверены по фактическим размерам и просмотрены через `view_image`. Экспорт выполнен Chrome DevTools с эмуляцией viewport 1440 × 900 и 390 × 844, devicePixelRatio 1. Browser plugin отсутствует; при зависании Chrome DevTools мобильный кадр загрузки переснят через доступный Playwright. На нём исправлена неполная отрисовка содержимого поля при первом снимке.

Сверены пять аспектов концепта и макетов: порядок и тексты, центрированная композиция, системная типографика, светлая палитра со стеклянными поверхностями, ткань/пропорции и отступы. Поиск виден без прокрутки, горизонтального переполнения нет, мобильный диалог помещается целиком. Console последних проверенных состояний не содержит ошибок и предупреждений. Отступления от ImageGen описаны выше: экспорты приводят художественные концепты к размерам дизайн-проекта. Это проверка соответствия статичных макетов, не готового приложения.

## Граница этапа

Макеты задают внешний вид состояний, но не проверяют реальный поиск, debounce, abort, фокус рабочего диалога или производительность WebGL. Эти проверки остаются в контрольных точках плана. Материалы `docs/design/` не подключены к приложению и не должны загружаться вместе с ним.
