# Стек проекта Country Search

Основание: [ТЗ](TASK.md). Границы модулей — в [архитектуре](ARCHITECTURE.md). Статус сверён с кодом и package-lock.json 2026-11-13.

## Реализованный стек

| Область    | Решение                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------ |
| Приложение | TypeScript, DOM API, обычный CSS; без UI-фреймворка и backend                                                      |
| Поиск      | fetch, AbortController, ручной таймаут; countries.dev                                                              |
| Состояние  | Собственный контроллер, debounce 300 мс, таймаут 10 секунд                                                         |
| Бонусы     | Собственный FIFO-кэш: 50 ответов / 5 минут; общие запросы с независимой отменой; история пяти строк в localStorage |
| Сцена      | Нативный WebGL, процедурная ткань, изображения флагов; статичный fallback                                          |
| Компиляция | tsc, строгий TypeScript, ES-модули NodeNext; src → dist                                                            |
| Тесты      | Vitest, Node без DOM, mock fetch и fake timers; 80 тестов на этапе 13                                              |
| Проверки   | ESLint, Prettier; Husky/lint-staged в pre-commit, npm test в pre-push                                              |
| Разработка | npm, http-server на 127.0.0.1:8080; tsc --watch во втором терминале                                                |
| Публикация | Статический хостинг; размещение и финальная проверка ещё впереди                                                   |

Динамическая разметка создаётся DOM API; сторонние библиотеки debounce/кэша отсутствуют. Vite используется тестовой инфраструктурой, а не сборкой приложения. Runtime npm-зависимостей нет.

## Закреплённые версии

Все десять пакетов — точные devDependencies. Версии manifest и lock-файла сверены без изменения зависимостей.

| Пакет             | Версия  |
| ----------------- | ------- |
| @eslint/js        | 10.0.1  |
| eslint            | 10.14.0 |
| http-server       | 14.1.1  |
| husky             | 9.1.7   |
| lint-staged       | 17.6.0  |
| prettier          | 3.10.1  |
| typescript        | 6.0.3   |
| typescript-eslint | 8.72.2  |
| vite              | 8.3.8   |
| vitest            | 5.1.0   |

Первоначальная установка проверялась с Node.js 24.14.1 и npm 11.11.0; это запись окружения этапа настройки, не требование ТЗ. Для повторяемой установки используйте npm ci по [package-lock.json](../package-lock.json). Поддерживаемый Node определяется engines установленных инструментов. Команды и запуск — в [README](../README.md).

Скрипты build/typecheck/start/dev/test/lint/format/format:check/prepare заданы в [package.json](../package.json). start сначала собирает приложение, dev наблюдает за TypeScript; CSS отдаётся напрямую. Для публикации нужны index.html, dist, src/styles и assets, а не один dist.

## Проверки и ограничения

На этапе 13 прошли 80 тестов, typecheck, lint и build; проверены браузером кэш, история, отказ localStorage и мобильная компоновка. В этапе 14 меняется документация, поэтому повторный запуск тестов приложения не требуется. Следующая полная проверка — пункт 15 [плана](IMPLEMENTATION_PLAN.md).

Сохраняется историческое сообщение npm audit этапа настройки о 10 пакетах moderate в цепочках инструментов разработки; свежий аудит на этапе 14 не выполнялся. Это не оценка текущей безопасности или применимости всех сообщений к браузерному коду. Детали предыдущих проверок сохранены в [прогрессе](progress.md).
