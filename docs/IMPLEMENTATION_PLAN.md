Работать по [ТЗ](TASK.md), [стеку](STACK.md), [архитектуре](ARCHITECTURE.md) и [дизайн-проекту](DESIGN_PROJECT.md). Завершённые этапы отмечать здесь, результаты контрольных точек — в [прогрессе](progress.md).

Комплексные проверки проводить только в контрольных точках ниже; повторять их после исправлений затронутого поведения. Разрешения на Git, установку пакетов и публикацию регулируются [общими правилами](../.agents/rules/workflow.md); уже полученные разрешения повторно не запрашивать.
