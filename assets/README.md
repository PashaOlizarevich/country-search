# Визуальные ресурсы

## Флаг Японии

[`flags/jp.svg`](flags/jp.svg) — локально созданная геометрическая версия: белое поле 900 × 600, красный круг с центром (450, 300) и радиусом 180. Соотношение сторон 3:2, диаметр круга — 3/5 высоты. Геометрия и цвета white/deep red сверены с [Cabinet Office of Japan](https://www.cao.go.jp/en/flag_anthem.html); оттенок `#BC002D` соответствует [справочному SVG Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_Japan.svg).

Сторонний графический файл не скачивался. Источник Commons помечает изображение государственного флага как public domain. Источники указаны для происхождения символики; это не утверждение о статусе всех государственных символов во всех юрисдикциях. SVG используется как статичный пример, favicon и текстура WebGL.

## Флаги результатов поиска

Рабочие изображения загружаются по flags.svg/png из ответа countries.dev. Сохранённые [fixtures](../tests/fixtures/README.md) содержат ссылки на flagcdn.com; файлы этих флагов в репозиторий не копируются. [Flagcdn](https://flagcdn.com/) и [руководство Flagpedia](https://flagpedia.net/download/api), проверенные 2026-11-13, описывают бесплатное встраивание и происхождение векторных файлов из Wikimedia Commons; обратная ссылка приветствуется. Бесплатный CDN не является общей лицензией Creative Commons на все материалы. Индивидуальные лицензии каждой возможной картинки API здесь не подтверждены; для самостоятельного распространения отдельного набора нужны сведения его источников.

Лицензия задания находится в [TASK_LICENSE.txt](../docs/TASK_LICENSE.txt) и не распространяется автоматически на внешние картинки или весь код приложения. Лицензии npm-пакетов остаются в соответствующих пакетах; они не переопределяются этим документом.

## Материалы макетов

В [docs/design](../docs/design/README.md) хранятся концепт и тканевый референс, созданные встроенным OpenAI ImageGen 2026-11-12, а также экспорты макетов. Это отдельные дизайнерские материалы, они не подключены к приложению и не входят в бюджет его ресурсов.

Сгенерированный тканевый референс показывает освещение и складки; он не является точной текстурой государственного флага или готовой анимацией. Для реализации рисунка использовать `jp.svg`. Условия сгенерированных материалов описаны в каталоге макетов.
