# Управление поиском

searchHistory.ts хранит пять нормализованных запросов через переданный доступ к Storage, проверяет JSON и продолжает работу в памяти при ошибке чтения/записи. main добавляет только актуальные results/empty; кнопки истории повторяют запрос немедленно.

searchState.ts описывает состояния idle, waiting, loading, empty, results и error. Каждое содержит нормализованный query; только results содержит countries, только error — errorKind и исходную error. Смена ввода сразу убирает результаты из состояния.

createSearchController({ onState, request?, debounceMs?, timeoutMs? }) из searchController.ts возвращает getState(), setQuery(value), clear(), retry() и destroy(). onState получает начальный idle и последующие состояния. По умолчанию request — существующий searchCountries, debounce — 300 мс, таймаут — 10 секунд от начала запроса. Для тестов можно передать функцию запроса. onState должен быть синхронным и не бросать исключений.

setQuery немедленно отменяет ожидающий debounce, очищает таймаут и вызывает abort активного запроса, затем планирует новый. clear отменяет обе стадии и публикует idle. retry немедленно запускает текущий непустой запрос, отменяя предыдущий запуск и ожидание. destroy идемпотентен: отменяет работу и запрещает дальнейшие уведомления и действия.

Каждый запрос имеет свой AbortController. Ввод/очистка/повтор/уничтожение отменяют его с AbortError, таймер — с TimeoutError. Это ручная связка источников отмены с одним передаваемым в API сигналом. Таймер освобождается после успеха, ошибки и отмены. revision и идентичность active защищают состояние дополнительно к настоящему abort, включая callbacks, которые не соблюдают сигнал. Таймаут сразу публикует ошибку и исключает поздний результат.

Код не обращается к DOM. 18 тестов контроллера проверяют жизненный цикл, stale-обработчики, повтор, таймаут и очистку ресурсов. Отдельный `searchRace.test.ts` использует настоящий `searchCountries` и мок `fetch`: новый ответ приходит раньше старого, отменённый запрос отклоняется с `AbortError`, итоговое состояние содержит только новую страну. Подключение UI относится к пункту 12.
