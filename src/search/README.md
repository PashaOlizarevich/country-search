# Управление поиском

Здесь появятся `searchState.ts`, `searchController.ts` и `searchErrors.ts`: состояние поиска, координация запросов, немедленная отмена и классификация ошибок.

Код не обращается к DOM. Интерфейс передаёт новый текст и получает изменения состояния через согласованный контракт. Контроллер управляет временем жизни запроса; API выполняет запрос, UI отображает результат.

Обработку ошибок и сценарии отмены сначала описываем тестами.
