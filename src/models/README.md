# Модели данных

Здесь появятся `country.ts` с типами и `mapCountryResponse.ts` с чистым преобразованием ответа API в модель страны. Форму ответа проверяем перед описанием типов; непроверенные данные не приводим к типу принудительно.

Слой не обращается к DOM и сети. Преобразование реализуем после падающих тестов.
