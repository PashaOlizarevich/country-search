# Модели данных

`country.ts` описывает модель UI с полями для карточки и подробностей. `demoCountries.ts` содержит явно демонстрационную Японию и локальный URL точного флага; это не схема ответа API и не рабочие результаты поиска. Неизвестные значения обозначаются `null`; пустой список границ означает известное отсутствие сухопутных границ.

`mapCountryResponse.ts` с чистым преобразованием ответа API появится на логическом этапе. Форму ответа проверяем перед описанием сырых типов; непроверенные данные не приводим к типу принудительно.

Слой не обращается к DOM и сети. Преобразование реализуем после падающих тестов.
