# Интерфейс

`createApp.ts` создаёт статичный первый экран через DOM API и возвращает типизированные ссылки на корневой узел, отключённое поле, статус и скрытую область результатов. Демонстрационная страна передаётся из `main.ts`. Результаты не подставляются, обработчики поиска и анимация ещё не подключены.

Следующие модули: `searchForm.ts`, `countryCard.ts`, `countryDetails.ts`, `searchStatus.ts`.

Создают элементы через DOM API и отображают переданные данные. Сетевые запросы и правила отмены остаются вне UI. События ввода передаются управлению поиском. Сначала внешний вид проверяется на демонстрационных данных.
