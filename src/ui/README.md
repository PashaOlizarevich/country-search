# Интерфейс

`createApp.ts` соединяет форму, карточки, статусы и нативный `dialog`. `searchForm.ts` передаёт ввод и очищает поле; `countryCard.ts` открывает подробности; `searchStatus.ts` отображает idle/waiting/loading/results/empty/error и действия повтора/очистки. `countryDetails.ts` удерживает фокус на единственной кнопке диалога, восстанавливает фокус и прокрутку после закрытия. `dom.ts` создаёт текстовые узлы, форматирует значения и обрабатывает отсутствие или сбой флага.

Сетевых запросов и debounce здесь нет. Временное подключение демоданных находится в `main.ts`. `destroy()` освобождает обработчики и удаляет интерфейс.
