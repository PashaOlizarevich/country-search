# Вспомогательные функции

Собственный debounce.ts откладывает callback до истечения delay после последнего вызова и передаёт последние аргументы. Метод cancel() отменяет ожидающий таймер; функцию можно использовать повторно. Каждая обёртка имеет независимый таймер. Задержку выбирает вызывающий код; callback не привязывает this, поэтому методы передаются через стрелочную функцию или bind.

Шесть тестов рядом используют fake timers: задержка, перезапуск, отмена, независимость экземпляров, повторный вызов из callback и нулевая задержка. DOM и сведения о странах отсутствуют.
